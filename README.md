# 🐰 ReplyRabbit AI
**An Intelligent Customer Support SaaS built with the MERN Stack.**

### 🚀 Key Features
* **AI Training Lab:** Teach the AI your specific business policies.
* **Dynamic Dashboard:** Manage and delete tickets in real-time.
* **AI Drafting Engine:** Automated context-aware responses based on training data.
* **Public Contact Portal:** Real-time ticket submission for customers.

### 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS v4, Lucide Icons.
* **Backend:** Node.js, Express.js.
* **Database:** MongoDB via Mongoose.
* **State Management:** React Hooks (useState, useEffect).
